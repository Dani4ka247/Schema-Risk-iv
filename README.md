# Schema-Risk-iv

>  все пунктирные линии - управляющие сигналы с CU 

# описание Control unit
>на вход CU приходит opcode(для команд) и flags(для переходов)
>
>опкод обрабатывается в decoder lut в адрес микропрограммы
>
>в microcode rom хранятся микропрограммы (по тактам)
>
>на их основе отправляются управляющие сигналы 
>
>step counter используется для работы с  microcode rom
